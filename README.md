## 💡 Why This Project Matters

<div style="background-color:#f0fdf4; padding:18px; border-radius:12px; border-left:6px solid #22c55e;">

Most airlines already collect customer feedback —  
the challenge is **knowing where to act**.

This project:
✔ Identifies **high-impact service drivers**  
✔ Separates *noise* from *signal*
